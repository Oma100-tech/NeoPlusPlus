==================================================
WELCOME TO NEOJAVA RUNTIME
==================================================

NeoJava is the next-generation Java-compatible runtime and launcher designed to deliver performance, simplicity, and flexibility to developers, gamers, and software enthusiasts alike.

Our goal is to evolve the Java ecosystem with enhanced speed, modern UI experiences, and innovative features that empower both professionals and hobbyists.

==================================================
FEATURES
==================================================

- Sleek, modern launcher UI.
- Automatic detection of NeoJava JDK/JRE installations.
- Supports LTS (Long Term Support) and STS (Short Term Support) versions.
- Built-in error detection and user-friendly messages.
- Lightweight design optimized for performance.
- Minimize to tray feature.
- Future support for auto-update mechanisms.
- Potential mod loader support in future versions.

==================================================
INSTALLATION GUIDE
==================================================

1. Download the NeoJava package (JDK or JRE) and the NeoJava Launcher .
2. Extract the contents into your desired folder.
3. Verify that NeoJava.exe resides in the /bin directory.
4. Launch NeoJavaLauncher.exe.
5. Choose your desired version and begin using NeoJava.

==================================================
SYSTEM REQUIREMENTS
==================================================

Minimum:
- Windows 10 or later.
- .NET Desktop Runtime.
- 4GB RAM.

Recommended:
- 8GB or more RAM.
- NeoJava JDK or JRE installed.

==================================================
TROUBLESHOOTING
==================================================

If NeoJava Runtime fails to start:
- Ensure NeoJava.exe exists in the expected directory.
- Verify that .NET Desktop Runtime is installed and updated.
- Disable any antivirus software that may block the launcher.
